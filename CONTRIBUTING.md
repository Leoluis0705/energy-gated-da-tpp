# Contributing

This repository is an archival research artifact. Changes that affect reported
results must include a test, regenerated source table or figure, an updated
validation report, and a clear provenance note. Do not overwrite frozen input
files or historical outputs.

Do not commit credentials, VASP executables, POTCAR data, or large raw VASP
outputs. Reported-result fixes should be released under a new version tag so
that the manuscript-linked release remains immutable.
