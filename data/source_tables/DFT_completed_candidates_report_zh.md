# 已完成 LiCr₂O₄ 候选的 DFT 结果报告

生成日期：2026-07-29  
批次：`prospective_cr_discovery_v2`

## 1. 结论摘要

本报告覆盖4个已经完成完整计算链的 LiCr₂O₄ 生成结构：job_079、job_126、job_196和job_234。四个候选均完成晶胞/离子松弛和独立static计算，电子计算正常结束，松弛后的最大残余力均不高于0.05 eV/Å，自动结构检查未判定晶胞坍塌。

在本批次内部自洽的PAW–PBE+U口径下，形成能分为两组：

- job_079与job_126：约−2.165至−2.168 eV/atom；
- job_196与job_234：约−2.034 eV/atom。

job_126给出四者中最负的形成能（−2.167619 eV/atom），但这不等于它已经被证明为热力学稳定材料。当前尚未完成竞争相凸包、energy above hull、多磁态、声子或实验可合成性评价。

## 2. 计算协议

- 软件：VASP 6.5.1；
- 交换—关联泛函：PBE；
- PAW：现代PAW-PBE数据集；
- Cr修正：Dudarev PBE+U，\(U_{\mathrm{eff}}(\mathrm{Cr})=3.7\) eV；
- `ENCUT = 649 eV`；
- 自旋极化：`ISPIN = 2`；
- 电子收敛：`EDIFF = 1×10⁻⁶ eV`；
- 松弛力阈值：`EDIFFG = −0.05 eV/Å`；
- 松弛：`IBRION = 2`、`ISIF = 3`、`NSW = 200`；
- 展宽：`ISMEAR = 0`、`SIGMA = 0.05 eV`；
- `LASPH = TRUE`、`LMAXMIX = 4`；
- static：固定松弛后结构，`IBRION = −1`、`NSW = 0`；
- k点网格由约0.15 Å⁻¹的倒易空间间距规则生成，具体网格见结果表。

使用的单元素POTCAR身份通过SHA-256记录，但归档不包含POTCAR正文：

### 3.1 结构松弛

四个结构的体积变化为−1.36%至+2.92%，均未触发自动坍塌判据。job_196和job_234的最短原子间距约1.724 Å，虽然高于自动阈值1.2 Å，仍建议在用于材料学主张前检查具体原子对和局部配位环境。

四个结构松弛后的Fmax均低于预设0.05 eV/Å阈值。该结果支持“在当前计算协议下获得了可收敛的局部结构”，但不等价于热力学稳定、动力学稳定或可实验合成。

### 3.2 形成能

形成能使用以下内部一致公式：

\[
E_f =
\frac{
E_{\mathrm{LiCr_2O_4}}
-\mu_{\mathrm{Li}}
-2\mu_{\mathrm{Cr}}
-2E_{\mathrm{O_2}}
}{7}.
\]

参考能为：

- \(\mu_{\mathrm{Li}}=-1.90574968\) eV/atom；
- \(\mu_{\mathrm{Cr}}=-6.16417684\) eV/atom；
- \(E_{\mathrm{O_2}}=-9.89314292\) eV/molecule。

两个独立脚本对四个候选的形成能回算差异均低于\(10^{-15}\) eV/atom，满足预设的\(10^{-6}\) eV/atom一致性要求。完整输入与复算结果见 `formation_energy_recalculation.csv`。

job_079与job_126之间相差约2.713 meV/atom；job_196与job_234之间仅相差约0.030 meV/atom。后一个差异远低于通常的数值和模型系统误差，因此不能依据当前计算可靠区分job_196与job_234的稳定性排序。四个结构之间更明显的现象是两组形成能相差约0.13 eV/atom。

### 3.3 磁性与电子结构

当前测试磁初始化下，四个结构的最终总磁矩为4.864–4.937 μB/cell。报告只能使用“当前测试磁初始化下的收敛结果”，不能称为磁基态，因为尚未系统比较FM、AFM和亚铁磁构型。

解析得到的PBE+U带隙均小于0.004 eV。虽然解析器将其记录为非金属小带隙状态，但这些数值接近数值分辨率；更稳妥的表述是“近金属性/近零带隙”，不宜声称具有确定的半导体带隙。

## 4. 运行与中断记录

- job_079和job_126在各自第一次static尝试中正常完成；
- job_196和job_234的第一次static尝试因服务器意外关机中断；
- 两者使用已收敛的松弛结构重新执行第二次static，并分别在3.03和3.14小时后正常完成；
- 最终结果均来自完成的第二次static尝试；
- 中断尝试保留在原始归档中，未被覆盖。

本表记录的四个候选完成阶段合计约83.4个任务壁钟小时，不含job_196/job_234被关机打断的第一次static耗时，也不等于CPU核心小时。

job_234运行中出现“实空间晶格与倒易/k点晶格类别不完全一致”的VASP警告。该警告没有导致计算失败，最终电子计算正常收敛；若job_234进入论文核心结论，建议增加对称性容差或`ISYM=0`敏感性核验。

## 5. 数据身份与重要限制

1. 当前完成的job_126明确为`gen_0`，不是`gen_3`。论文、图表和候选冻结记录中必须使用完整ID，避免版本错配。
2. 文件名中的`fe_-0.xxx`或`fe_-1.xxx`字段是生成任务请求字段，不是本轮DFT形成能真值。
3. `same_scale_status = UNRESOLVED`。MatterGen请求值、ALIGNN标签与当前自洽DFT形成能尚未证明处于同一能量口径，不能直接比较区间命中。
4. 四个候选均为相同化学式LiCr₂O₄，但尚未对最终松弛结构做完整的StructureMatcher/SOAP去重。形成能接近不自动证明结构相同。
5. 未计算同口径竞争相和energy above hull，因此不能声称热力学稳定。
6. 未系统搜索磁构型、计算声子、进行有限温度分析或验证合成路径。
7. job_092未收敛，不属于本报告的“已完成候选”。
